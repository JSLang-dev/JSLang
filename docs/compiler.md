# Compiler

The initial compiler pipeline is source, lexer, tokens, parser, AST, checker, IR, and backend. v0.0.9 implements source positions, tokens, the lexer, a recursive-descent parser, an explicit AST, name resolution, primitive type checking, typed structs, and a C-emitting native backend with console runtime and conditional execution support. Use `jsl parse <file>` to print a deterministic AST representation, `jsl check <file>` to validate scopes, names, types, calls, return values, and struct fields, and `jsl build <file>` to create an executable.

The v0.0.9 backend supports multiple `i32` functions, `i32` parameters, local `i32`, `bool`, and `string` variables, integer, boolean, and string literals, unary, binary, and conditional expressions, direct function calls, return statements, `if`/`else`, and the native `console` API. It emits temporary C source and invokes the host C compiler. This is a bootstrap backend, not a JavaScript runtime or a permanent code-generation architecture.
