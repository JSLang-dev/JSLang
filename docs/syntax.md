# Syntax

v0.0.10 parses functions, variables, assignments, blocks, structs, returns, conditionals, expressions, calls, imports, and exports. `jsl check` validates the scope, name, primitive type, assignment, and struct-field rules described in [the language specification](language-spec.md). `jsl build` supports the documented native `i32`, `bool`, `string`, console, struct, conditional, and mutable-assignment subset.
